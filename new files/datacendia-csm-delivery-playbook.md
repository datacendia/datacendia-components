# Part 1: Welcome Bonus Delivery

## Timeline

```
DAY 0: Contract signed
       └── CSM notified
       └── Industry identified
       └── Data gathering begins

DAY 1-2: Analysis
         └── Public data collected
         └── Council generates report
         └── Draft reviewed

DAY 3: Quality Check
       └── Senior CSM reviews
       └── Personalization verified
       └── One "holy shit" number confirmed

DAY 4-5: Delivery
         └── Personal email sent
         └── PDF attached
         └── Soft CTA included

DAY 6-7: Follow-up (if needed)
         └── Check if received
         └── Offer to discuss
```

## Pre-Delivery Checklist

- [ ] Client company name correct throughout
- [ ] Industry-appropriate report selected
- [ ] At least 3 specific numbers about THEIR company
- [ ] At least 1 named competitor
- [ ] At least 1 "holy shit" finding (quantified pain)
- [ ] Recommendations are actionable
- [ ] PDF formatted cleanly
- [ ] Email drafted and reviewed

## Email Template (Welcome Bonus)

**Subject Line Options:**
- "Something for you before we kick off"
- "Ran something for you"
- "Before onboarding - thought you'd want this"
- "Found something interesting"

**Body Structure:**

```
Hey [FIRST NAME],

Welcome aboard. Before we start onboarding [next week / on DATE], 
I asked the Council to run something for you.

Attached is your [REPORT NAME] - it's not part of your package, 
just wanted you to see what we can do when we focus on [INDUSTRY].

One thing jumped out: [SPECIFIC FINDING WITH NUMBER]. 
[ONE SENTENCE IMPLICATION].

Free [DAY] if you want to dig in. If not, no worries - 
see you at onboarding.

[YOUR NAME]

P.S. - Feel free to share this with your [RELEVANT TEAM/PERSON]. 
They might find [SPECIFIC SECTION] interesting.
```

## Delivery Do's and Don'ts

### DO:
- ✅ Send from your personal email (not automated)
- ✅ Use casual, conversational tone
- ✅ Highlight ONE specific finding
- ✅ Make the CTA soft (no pressure)
- ✅ Suggest who else might want to see it
- ✅ Send mid-week (Tue-Thu) morning

### DON'T:
- ❌ Use corporate/formal language
- ❌ Overwhelm with multiple findings
- ❌ Make it feel like a sales pitch
- ❌ Send on Friday afternoon or Monday morning
- ❌ Use automated scheduling
- ❌ Forget the P.S. (it drives internal sharing)

# Part 2: 6-Month Loyalty Delivery

## Timeline

```
MONTH 5, WEEK 3: Preparation
                 └── Review account health
                 └── Pull 6-month usage data
                 └── Identify package pair
                 └── Note personalization signals

                 └── Run Council prompts
                 └── Generate both packages
                 └── Draft deliverables

                   └── Senior review
                   └── Personalization verification
                   └── Second package recipient identified

MONTH 6, DAYS 5-7: Follow-up
```

## Pre-Call Preparation

### 1. Review Account Health
```
□ Usage trends (up/down/stable?)
□ Key decisions they've run
□ Which agents they engage most
□ Features used vs. unused
□ Support tickets or issues
□ Stakeholder engagement level
□ Renewal date and ARR
```

### 2. Personalization Signals
```
□ What decisions do they run most?
□ What DON'T they run that they should?
□ Who in their org uses Datacendia?
□ What themes recur in their deliberations?
□ What's happening in their industry right now?
□ Any recent company news (funding, M&A, leadership)?
```

### 3. Package Customization
```
□ Both packages reference their actual usage
□ Findings connect to decisions they've made
□ Recommendations build on their patterns
□ Specific to their company/situation
□ Named competitors relevant to them
□ Numbers specific to their scale/industry
```

## The Delivery Call

### Call Structure (30 minutes)

**Minutes 0-2: Opening**
```
"Hey [NAME], thanks for making time. Before we get into our 
regular check-in, I have something I wanted to share with you."
```

**Minutes 2-5: The Surprise**
```
"You've been with us 6 months now, and we've been watching how 
your team uses the Council. Based on what we've seen, we built 
two things specifically for you.

These aren't part of your contract - they're a thank you for 
being a great customer.

The first one is for you personally..."
```

**Minutes 5-10: Package A Walkthrough**
```
[Share screen if video call]

"This is your [PACKAGE A NAME]. We looked at [WHAT WE ANALYZED] 
and found [KEY FINDING].

The thing that jumped out is [SPECIFIC INSIGHT WITH NUMBER].

[Walk through 2-3 key sections briefly]

I'll send this over right after the call so you can dig in."
```

**Minutes 10-15: Package B Introduction**
```
"The second one is for your [DEPARTMENT] team. I thought 
[SPECIFIC PERSON] might find this useful.

It's your [PACKAGE B NAME]. We analyzed [WHAT WE ANALYZED] 
and the main finding is [KEY INSIGHT].

Would it be helpful if I sent this directly to [PERSON], 
or would you prefer to share it yourself?"
```

**Minutes 15-20: Discussion**
```
"Any initial reactions? Questions about what you're seeing?"

[Let them respond - they usually have questions]

[Offer to schedule deeper dive sessions if interested]
```

**Minutes 20-30: Regular Check-in**
```
"Okay, let me switch gears to our regular check-in..."

[Proceed with standard account review]
```

### Call Script Variations

**If they seem surprised:**
```
"Yeah, we do this for all our customers at the 6-month mark. 
We want to make sure you're getting value beyond just the 
platform itself. These are things the Council can see that 
we thought would be useful."
```

**If they ask about cost:**
```
"There's no charge - this is just part of being a Datacendia 
customer. We want to make sure you're successful, and these 
packages help us demonstrate value beyond the day-to-day 
deliberations."
```

**If they want to include others:**
```
"Absolutely. I can schedule a separate session to walk through 
[PACKAGE B] with [THEIR COLLEAGUE] if that would be helpful. 
Or I can join a meeting you're already having."
```

**If they're lukewarm:**
```
"No pressure to dig in right away. I'll send both over and 
you can review when you have time. If any questions come up, 
just let me know."
```

# Part 3: Response Handling

## Positive Responses

### "This is amazing!"

**Your response:**
```
"Glad it's useful! We've found that [SPECIFIC CAPABILITY] 
really resonates with [INDUSTRY] companies. 

A few customers have asked us to do follow-up analyses on 
[RELATED TOPIC] - would that be valuable for you?

Also, feel free to share with anyone internally who might 
benefit. We can generate similar views for other teams if 
there's interest."
```

**Action:** Note expansion opportunity, schedule follow-up

---

### "Can you do this for [other team/topic]?"

**Your response:**
```
"Absolutely. We can run similar analyses for [THEIR REQUEST]. 
Let me check what data we'd need and get back to you with 
a timeline.

In the meantime, feel free to share these with [OTHER TEAM] - 
they might spark some ideas about what would be useful for them."
```

**Action:** Log as expansion lead, schedule scoping call

---

### "I'm sharing this with [EXECUTIVE]"

**Your response:**
```
"Perfect. If [EXECUTIVE] has questions or wants a walkthrough, 
I'm happy to schedule time. Sometimes it helps to have someone 
who can explain the methodology.

Also, I can generate an executive summary version if that 
would be more appropriate for [EXECUTIVE]'s level."
```

**Action:** Prepare for exec engagement, note internal champion

---

## Neutral Responses

### "Thanks, I'll take a look"

**Your response:**
```
"Sounds good. The [SPECIFIC SECTION] is probably the most 
relevant given [SOMETHING HAPPENING IN THEIR BUSINESS]. 

Let me know if any questions come up."
```

**Action:** Schedule follow-up in 5-7 days

---

### "We're pretty busy right now"

**Your response:**
```
"Totally understand. These will be here when you have time. 
The [SPECIFIC FINDING] might be worth a quick look when 
you have 5 minutes - it's on page [X].

I'll check back in a couple weeks."
```

**Action:** Schedule follow-up in 2-3 weeks, note timing

---

## Skeptical Responses

### "Where did you get this data?"

**Your response:**
```
"Great question. Package A uses your actual usage data from 
the platform - things like which decisions you've run, 
patterns we've noticed, etc.

Package B combines your usage data with [PUBLIC SOURCES - 
industry benchmarks, market data, etc.].

We're careful to only use data you've already shared with us 
or that's publicly available. Happy to walk through the 
methodology if you'd like."
```

**Action:** Offer methodology deep-dive, address concerns

---

### "This doesn't seem accurate"

**Your response:**
```
"I want to make sure we get this right. Can you tell me 
what seems off?

[Listen to their concerns]

That's helpful feedback. Let me [investigate / clarify / 
correct] and get back to you. We may have [missed context / 
used outdated data / made an assumption] that we can fix."
```

**Action:** Investigate immediately, correct if needed, document feedback

---

### "I'm not sure this is useful for us"

**Your response:**
```
"Fair enough. What would be more useful?

[Listen]

That's helpful. We can probably generate something more 
targeted to [THEIR STATED NEED]. Let me see what we can do."
```

**Action:** Log feedback, consider custom analysis, adjust future packages

---

## Negative Responses

### "We're thinking about not renewing"

**Your response:**
```
"I appreciate you being direct. Can you help me understand 
what's driving that?

[Listen carefully - don't interrupt]

[Address specific concerns if possible]

These packages are actually designed to show value beyond 
the day-to-day platform. If [SPECIFIC FINDING] is accurate, 
that's [QUANTIFIED IMPACT] you could address with Datacendia.

Can we schedule time to discuss how we might adjust to 
better meet your needs?"
```

**Action:** Escalate to renewal risk process, involve leadership

---
