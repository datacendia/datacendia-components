## 1. LIVE MONITOR (1 minute)
**URL:** `/cortex/monitor/live`

**Navigate:** Core Suite → The Council → Live Monitor

**Say:**
> "Every AI-assisted decision appears here in real time — before execution. This is intent review before action, not logging after the fact. You see who participated, what evidence was used, and what requires human approval."

**Show:**
- Point to decision badges (ALLOW/BLOCK/ESCALATE)
- Click Pause button → "Humans can pause anytime"

**Transition:** "Let me show you how decisions actually get made..."

---

## 2. THE COUNCIL (2 minutes)
**URL:** `/cortex/council`

**Navigate:** Core Suite → The Council

**Say:**
> "This is The Council — multiple AI agents deliberate before any decision. This is not a virtual board replacing executives. It's a structured challenge mechanism that forces dissent to surface before humans decide."

**Do:**
1. Click **"New Deliberation"**
2. Select **"Contract Review"**
3. Enter:
   ```
   Should we proceed with the Thomson Reuters Westlaw integration 
   under a 3-year $2.4M/year agreement?
   ```
4. Click **"Begin Deliberation"**

**While agents deliberate, say:**
> "Legal is reviewing indemnity clauses using Westlaw citations. Finance is calculating TCO. Risk is evaluating vendor dependency. Compliance is checking data residency. If any agent sees a problem, they formally dissent — and that dissent becomes part of the permanent record."

**Show:** Point to any dissent indicator if one appears

**Transition:** "Every word of this deliberation is captured in what we call Decision DNA..."

---

## 3. DECISION DNA (1 minute)
**URL:** `/cortex/intelligence/decision-dna`

**Navigate:** Core Suite → Decision DNA

**Say:**
> "This is the complete genetic code of that decision. What data went in, how it was processed, which agents were involved, what came out. This hash at the top is like DNA — if anyone tampers with any part of this record, the hash breaks. It's computationally impractical to alter without detection."

**Do:**
1. Click on a recent deliberation
2. Point to the Merkle root hash
3. Click **"Verify Integrity"** → "Just verified it hasn't been tampered with"

**Transition:** "When a regulator asks to see this..."

---

## 4. REGULATOR'S RECEIPT (1 minute)
**URL:** `/cortex/compliance/regulators-receipt`

**Navigate:** Core Suite → Regulator's Receipt

**Say:**
> "When the SEC, FINRA, or any regulator says 'show me your AI governance' — you don't scramble. You click a button."

**Do:**
1. Select the deliberation from earlier
2. Check: SEC, FINRA, SOC 2
3. Click **"Generate Receipt"**
4. Show the preview
5. Click **"Download PDF"**

**Say:**
> "This takes minutes, not weeks. The PDF is for humans — lawyers, regulators, board members. The evidence bundle is machine-verifiable with cryptographic proofs."
