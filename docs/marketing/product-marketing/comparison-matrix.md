## Quick-Reference: When to Position Against Each Competitor

| Competitor | They Win When... | We Win When... |
|-----------|-----------------|----------------|
| **Palantir** | Customer wants data analytics/visualization | Customer needs AI decision governance + proof |
| **C3.ai** | Customer wants custom AI application platform | Customer needs governance for AI decisions |
| **IBM OpenPages** | Customer is all-IBM and wants GRC module | Customer wants AI-native governance, not legacy GRC |
| **OneTrust** | Need is purely data privacy / consent mgmt | Need is AI decision governance + compliance |
| **DataRobot** | Need is ML model lifecycle / MLOps | Need is decision-level governance, not model monitoring |
| **Relativity** | Need is purely e-discovery document review | Need is legal decision governance (8 schemas) or cross-industry |
| **Veeva** | Need is clinical trial operations mgmt | Need is clinical decision governance + multi-vertical |
| **Internal** | Google/Meta-scale with unlimited engineering | Everyone else (cost, time, maintenance) |
| **Big 4** | Customer needs strategy/organizational change | Customer needs working software, not another assessment |
| **Status quo** | Regulation doesn't apply (yet) | EU AI Act, SEC, FDA, or any regulatory mandate |
