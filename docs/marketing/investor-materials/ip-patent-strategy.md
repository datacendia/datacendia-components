## 3. Patent Strategy

### Provisional Patent Applications (Priority)

**Patent 1: "System and Method for Multi-Agent AI Deliberation with Immutable Decision Proof"**
- Claims: multi-agent deliberation architecture, adversarial cross-examination, formal dissent capture, Merkle-signed decision packets, forensic-grade, independently verifiable evidence export
- Prior art differentiation: no existing system combines multi-agent deliberation + immutable proof + regulatory compliance + sovereign deployment
- **Estimated filing cost:** $5,000-$8,000 (provisional)

**Patent 2: "Crisis Immunization Framework: 9 Decision Primitives for Institutional AI Governance"**
- Claims: the 9 primitives as a systematic framework, machine-enforcement methodology, primitive-to-regulation mapping, institutional immune system scoring (IISS)
- Prior art differentiation: no existing framework defines these 9 specific primitives as a complete governance system
- **Estimated filing cost:** $5,000-$8,000 (provisional)

**Patent 3: "Sovereign AI Decision Governance with Post-Quantum Cryptographic Proof"**
- Claims: air-gapped AI governance deployment, data diode integration, TPM-attested decisions, post-quantum signed decision packets, QR air-gap bridge
- **Estimated filing cost:** $5,000-$8,000 (provisional)

### Non-Provisional Timeline
- **Year 1:** File 3 provisional patents ($15-24K total)
- **Year 2:** Convert to non-provisional based on commercial traction ($15-25K each)
- **Year 3+:** Continuation applications, international (PCT) if warranted

## 4. Trade Secret Protection

| Secret | Protection Mechanism |

| Vertical decision schema validation logic | Private repo, not in open-source core |
| AI model routing algorithms | Internal configuration, not exposed via API |

### Protective Measures
- All employees/contractors sign IP assignment + NDA
- Source code in private repository (datacendia-components)
- Open-source core (datacendia-core) contains only community features
- Enterprise features never published in open-source
- Customer data: zero-access architecture (sovereign-first)
