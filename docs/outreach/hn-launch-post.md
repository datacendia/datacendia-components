# Show HN: Datacendia – AI agents that argue with each other before making decisions (with audit trail)

Hey HN,

I'm Stuart, solo founder building Datacendia.

The core idea: most AI tools give you one model's answer. For high-stakes decisions, that's usually the wrong shape of system. I built a council engine where specialized agents disagree, challenge assumptions, and force each other to justify claims. The output is a decision record with an audit trail, not just a final paragraph.

What changed my mind while building this: **deliberation beats dictation** for governance-heavy decisions.

Concrete example from one run: in a CRE acquisition scenario, the headline looked like a 22% discount. A specialist agent reframed it to a 2.2% discount to fair value after adjusting assumptions. That single cross-exam changed the recommendation and the risk posture.

This is not "AI replaces decision-makers." It's closer to structured adversarial review before humans sign off.
