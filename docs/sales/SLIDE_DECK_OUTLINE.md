## Design Notes

### Typography
- Headlines: Bold, 36-48pt
- Body: Regular, 18-24pt
- Never more than 6 lines per slide
- Use speaker notes for detail

### Imagery
- Dark backgrounds (navy/black)
- Glowing accents (cyan, gold)
- Product screenshots with subtle glow effects
- Avoid stock photos—use abstract/geometric visuals

### Animation
- Minimal—builds where necessary
- No transitions between slides
- Video/GIF for demo moments only

### Handout Version
- Create PDF version with speaker notes visible
- Include appendix slides in handout
- Add page numbers for reference

## Presentation Tips

1. **Open with the question** - The "regulator walks in" hook
2. **Show, don't tell** - Live demo > bullet points
3. **Pause for reaction** - After Council demo, let it sink in
4. **Address the skeptic** - Proactively handle "why not Copilot?"
5. **End with action** - Always book the next meeting
