# 📬 Industry Welcome Bonus: Delivery Templates

**The emails, formats, and scripts that make the surprise land.**

---

## Part 1: Email Templates

### Master Email Structure

Every delivery email follows this formula:
1. **Personal greeting** (not automated-feeling)
2. **The surprise** ("Before we start onboarding...")
3. **What it is** (one sentence)
4. **The hook** (specific finding that creates curiosity)
5. **Soft CTA** (offer to discuss, no pressure)

## Part 3: Delivery Checklist

### Before Sending

- [ ] Client name spelled correctly throughout
- [ ] Logo obtained and placed on cover
- [ ] All numbers are specific to THIS client (no placeholders)
- [ ] At least one competitor mentioned by name
- [ ] At least one "holy shit" number that creates urgency
- [ ] Senior team member reviewed
- [ ] AE has read entire report and can discuss any section
- [ ] PDF exported cleanly (no formatting issues)

### Email Checklist

- [ ] Subject line is casual, not corporate
- [ ] First line uses their first name
- [ ] "Not part of your package" is mentioned
- [ ] One specific finding highlighted to create curiosity
- [ ] Soft CTA (offer to discuss, no pressure)
- [ ] P.S. suggests who else might want to see it
- [ ] Sent from AE's personal email (not automation)

### Timing

| Day | Action |
|-----|--------|
| Day 0 | Contract signed |
| Day 1 | Analysis begins |
| Day 2-3 | Report drafted |
| Day 3-4 | Senior review |
| Day 4-5 | Delivery |
| Day 6-7 | Follow-up if no response |
| Day 7-10 | Onboarding begins |

## Part 4: Response Handling

### If They Love It

**They reply enthusiastically:**

```
"This is amazing - let me get my [ROLE] on a call."
```

**Your response:**
```
Great - happy to walk through it with anyone who'd find it useful. 
I can also generate similar analyses for specific business units 
or regions once we're fully integrated.

What time works for your team?
```

---

### If They're Skeptical

**They question the data:**

```
"Where did you get these numbers? This seems off."
```

**Your response:**
```
Fair question. Everything in this report came from public sources - 
[list specific sources]. Happy to share our methodology.

That said, this is just a taste based on external data. Once we 
integrate with your internal systems, the analysis gets much more 
precise. Sometimes external data does miss context.

Want to compare what we found with your internal view?
```

---

### If They Go Silent

**Day 7, no response:**

```
Subject: Re: [Original subject]

Hey [FIRST NAME],

Just checking if you had a chance to look at the analysis. No 
pressure either way - just want to make sure it landed.

If any questions came up, happy to clarify before onboarding.

[AE NAME]
```

### If They Share Internally

**They mention sharing with colleagues:**

```
"I forwarded this to our CFO and COO."
```

**Your response:**
```
Perfect. Happy to generate a similar view focused on their specific 
areas if useful - the Council can cut the analysis different ways.

Let me know if they have questions or want a focused version.
```
