## MODE CHARACTERISTICS

### ⚔️ WAR ROOM
- **Agents:** Attack each other's proposals
- **Output:** Debate record + conditional decision
- **Duration:** 5-15 minutes
- **Best for:** Contested strategic decisions

### 🔍 DUE DILIGENCE
- **Agents:** Skeptical, evidence-demanding
- **Output:** Red flags + confidence levels + gaps
- **Duration:** 10-20 minutes
- **Best for:** High-stakes commitments

### 💡 INNOVATION
- **Agents:** Build on each other ("Yes, and...")
- **Output:** Idea list + feasibility sketch
- **Duration:** 5-10 minutes
- **Best for:** Generating possibilities

### 🛡️ COMPLIANCE
- **Agents:** Risk-focused, conservative
- **Output:** Regulation matrix + control recommendations
- **Duration:** 10-15 minutes
- **Best for:** Regulatory exposure

### 🚨 CRISIS
- **Agents:** Action-oriented, decisive
- **Output:** Action table with owners/deadlines
- **Duration:** 2-5 minutes
- **Best for:** Emergencies requiring speed

### 🎯 EXECUTION
- **Agents:** Tactical, accountable
- **Output:** Project plan + milestones + resources
- **Duration:** 10-15 minutes
- **Best for:** Turning decisions into action

### 🔬 RESEARCH
- **Agents:** Objective, evidence-based
- **Output:** Findings + confidence + limitations
- **Duration:** 10-20 minutes
- **Best for:** Understanding data

### 💰 INVESTMENT
- **Agents:** Financial, ROI-focused
- **Output:** ROI + scenarios + alternatives
- **Duration:** 5-10 minutes
- **Best for:** Budget decisions

### 🤝 STAKEHOLDER
- **Agents:** Empathetic, political
- **Output:** Stakeholder map + communication plan
- **Duration:** 5-15 minutes
- **Best for:** Change with people impact

### ⚡ RAPID
- **Agents:** One sentence each
- **Output:** Decision + rationale
- **Duration:** 1-2 minutes
- **Best for:** Low-stakes, time-sensitive

### 🎓 ADVISORY
- **Agents:** Educational, patient
- **Output:** Frameworks + examples + takeaways
- **Duration:** 5-10 minutes
- **Best for:** Learning and training

### 🏛️ GOVERNANCE
- **Agents:** Formal, precedent-aware
- **Output:** Policy document + rationale
- **Duration:** 10-15 minutes
- **Best for:** Decisions that set precedent
