Governance Guarantees

Guarantee Mechanism
Human oversight enforced Escalation paths require human review for high-risk decisions
Dissent preserved Agent disagreements cryptographically committed before final decision
Overrides audited Override events record approver identity, justification, and timestamp
Decisions replayable Full deliberation replay with context, reasoning, and evidence
Datacendia is a certification-enabling layer. It reduces audit scope by producing immutable decision evidence. The platform does not claim to replace regulatory compliance programs — it provides the technical infrastructure that makes those programs provable.

Supply Chain Transparency

A complete Software Bill of Materials in CycloneDX 1.5 format is published at /trust/sbom.json and updated with each release. This meets US Executive Order 14028 requirements for software supply chain transparency.

Security Reporting

Datacendia maintains a responsible disclosure policy. Security researchers can report vulnerabilities via the process described at /.well-known/security.txt.
