## Sales Documentation

The `/sales` folder contains all materials for enterprise sales teams:

- **Battle Cards**: Competitive positioning and quick reference
- **Objection Handling**: Responses to common concerns
- **Regional Pricing**: Market-specific pricing strategies
- **Demo Scripts**: Guided demonstration flows
- **Case Studies**: Template for customer success stories

## Council Documentation

The `/council` folder contains documentation for the AI Council modes:

- **Cheat Sheet**: Quick reference for all 12 council modes
- **Demo Guide**: How to demonstrate council capabilities
- **Marketing**: Positioning and messaging for council features

## Implementation
