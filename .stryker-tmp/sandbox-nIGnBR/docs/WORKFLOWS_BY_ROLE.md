# 1. CEO (Chief Executive Officer)

## Primary Use Cases
- Strategic direction setting
- Board communication
- Crisis leadership
- M&A decisions
- Organizational alignment

## 1.1 Strategic Planning Cycle

```
ANNUAL STRATEGIC PLANNING
     │
     ▼
┌─────────────────────────────────────────────────────────────┐
│ CEO INITIATES COUNCIL DELIBERATION                          │
│                                                             │
│ "What should our 3-year strategic priorities be given       │
│ market trends, competitive landscape, and our capabilities?"│
│                                                             │
│ AGENTS ENGAGED:                                             │
│ • Chief Strategy: Market analysis, competitive positioning  │
│ • CFO: Financial capacity, investment thesis                │
│ • CMO: Customer trends, brand trajectory                    │
│ • CTO: Technology disruption, innovation opportunities      │
│ • Risk: Strategic risks, scenario planning                  │
│                                                             │
│ OUTPUT: Prioritized strategic initiatives with resource     │
│ requirements and success metrics                            │
└─────────────────────────────────────────────────────────────┘
     │
     ▼
CEO REVIEW & REFINEMENT
├── Challenge assumptions
├── Request scenario modeling
├── Test against board expectations
└── Validate resource availability
     │
     ▼
EXECUTIVE TEAM ALIGNMENT SESSION
├── Present Council synthesis
├── Discuss trade-offs
├── Assign initiative owners
└── Set quarterly milestones
     │
     ▼
BOARD PRESENTATION
├── Strategic narrative
├── Council-generated risk analysis
├── Investment requirements
└── Success metrics
```

## 1.2 CEO Crisis Command

```
CRISIS DETECTED (PR, operational, market, regulatory)
     │
     ▼
CEO ACTIVATES WAR ROOM
     │
     ▼
┌─────────────────────────────────────────────────────────────┐
│ EMERGENCY COUNCIL DELIBERATION                              │
│                                                             │
│ "[Crisis summary]. What's our response strategy?            │
│ What do I say publicly? What actions do we take?"           │
│                                                             │
│ ALL AGENTS ENGAGED - 5 minute response limit                │
│                                                             │
│ OUTPUT:                                                     │
│ • Immediate actions (first 60 minutes)                      │
│ • Public statement draft                                    │
│ • Stakeholder communication sequence                        │
│ • Risk mitigation steps                                     │
│ • Recovery timeline                                         │
└─────────────────────────────────────────────────────────────┘
     │
     ▼
CEO DECISION
├── Approve or modify response
├── Assign action owners
├── Set check-in cadence
└── Communicate externally
     │
     ▼
HOURLY COUNCIL UPDATES until stabilized
```

## 1.3 Board Meeting Preparation

```
T-7 DAYS: CEO REQUESTS BOARD PREP
     │
     ▼
┌─────────────────────────────────────────────────────────────┐
│ COUNCIL DELIBERATION                                        │
│                                                             │
│ "Prepare me for board meeting. What questions will they    │
│ ask? What's our narrative? Where are we vulnerable?"        │
│                                                             │
│ OUTPUT:                                                     │
│ • Executive summary (CEO talking points)                    │
│ • Anticipated questions with prepared answers               │
│ • Board member-specific concerns                            │
│ • Risk acknowledgment and mitigation narrative              │
│ • Investment asks with ROI justification                    │
└─────────────────────────────────────────────────────────────┘
     │
     ▼
T-3: PRE-WIRE KEY BOARD MEMBERS
     │
     ▼
T-1: REHEARSAL WITH EXECUTIVE TEAM
     │
     ▼
T-0: BOARD MEETING (Council on standby for real-time queries)
```

# 2. CFO (Chief Financial Officer)

## Primary Use Cases
- Financial planning & analysis
- Investment decisions
- Risk management
- Capital allocation
- Investor relations

## 2.1 Capital Allocation Decision

```
INVESTMENT REQUEST RECEIVED (CapEx, M&A, new initiative)
     │
     ▼
CFO INITIATES ANALYSIS
     │
     ▼
┌─────────────────────────────────────────────────────────────┐
│ COUNCIL DELIBERATION                                        │
│                                                             │
│ "Evaluate $[X]M investment in [Initiative]. What's the     │
│ ROI? What's the risk-adjusted return? Alternatives?"        │
│                                                             │
│ AGENTS ENGAGED:                                             │
│ • CFO Agent: NPV, IRR, payback, sensitivity analysis        │
│ • Risk: Downside scenarios, probability-weighted returns    │
│ • Chief Strategy: Strategic alignment score                 │
│ • COO: Operational feasibility, execution risk              │
│                                                             │
│ OUTPUT:                                                     │
│ • Financial model summary                                   │
│ • Risk-adjusted ROI                                         │
│ • Alternative use of capital comparison                     │
│ • Recommendation with confidence score                      │
└─────────────────────────────────────────────────────────────┘
     │
     ▼
CFO DECISION MATRIX
├── Compare against hurdle rate
├── Stack rank against other requests
├── Assess funding source (cash, debt, equity)
└── Determine approval path
     │
     ▼
APPROVAL → FUNDING → TRACKING
```

## 2.2 Quarterly Close & Forecast

```
QUARTER END
     │
     ▼
CLOSE PROCESS (standard)
     │
     ▼
┌─────────────────────────────────────────────────────────────┐
│ CFO POST-CLOSE COUNCIL QUERY                                │
│                                                             │
│ "Analyze Q[X] results vs plan. What drove variances?       │
│ What does this mean for full-year forecast?"                │
│                                                             │
│ OUTPUT:                                                     │
│ • Variance analysis by business unit                        │
│ • Root cause decomposition                                  │
│ • Updated full-year forecast (3 scenarios)                  │
│ • Cash flow implications                                    │
│ • Investor messaging recommendations                        │
└─────────────────────────────────────────────────────────────┘
     │
     ▼
CFO ACTIONS
├── Validate forecast with business leaders
├── Prepare earnings materials
├── Brief CEO and board
└── Update guidance (if public)
```
