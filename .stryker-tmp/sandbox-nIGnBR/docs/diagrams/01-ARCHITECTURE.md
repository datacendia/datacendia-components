## Component Responsibilities

| Layer | Components | Responsibility |
|-------|------------|----------------|
| **Frontend** | React + Vite | User interface, state management, routing |
| **API Gateway** | Express.js | Authentication, rate limiting, validation |
| **Services** | Node.js | Business logic, AI orchestration, integrations |
| **Data** | PostgreSQL, Redis, MongoDB, Neo4j | Persistence, caching, documents, graphs |
| **AI** | Ollama | Local LLM inference, embeddings |
